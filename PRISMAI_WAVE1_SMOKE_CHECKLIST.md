# PrismAI Wave 1 Smoke Checklist

Use this checklist before merging any rehab lane into `prismai/integration`.

For the March 27-28 rehab fixes, use the companion live operator checklist:

- `PRISMAI_MANUAL_LIVE_VERIFICATION_CHECKLIST.md`

## Desktop lane

- `desktop-tauri/runtime` exists and was generated by `corepack yarn prepare:core`
- `bootstrap.log`, `server.log`, and `collector.log` are written under the PrismAI desktop data directory
- development launch succeeds with `corepack yarn tauri:dev`
- packaged macOS launch succeeds or fails with a classified startup phase
- DMG-mounted launch is blocked with the install guidance message
- startup failures are distinguishable as install guard failure, migration/bootstrap failure, collector exit, server exit, port conflict, or readiness timeout

## Frontend lane

- login renders
- onboarding renders
- workspace shell renders
- settings render
- `/metacanonai` renders
- `/metacanonai/library` renders
- experimental routes only appear in dev mode or when `VITE_PRISM_EXPERIMENTAL_SURFACES=enabled`
- Repo Lab only appears when `VITE_PRISM_REPO_LAB=enabled` in addition to experimental surfaces
- Prism presence still updates during chat flows

## Server lane

- workspace chat still streams
- thread chat still streams
- document upload still reaches collector successfully
- collector embed flow still works
- mobile register/auth/bootstrap flows still work
- `/metacanonai/library/manifest` returns data
- `/metacanonai/library/collection` returns data
- `/metacanonai/library/item` returns data
- Repo Lab read surfaces require explicit enablement outside local development
- Repo Lab write surfaces require admin role plus explicit write enablement outside local development

## Integration lane

- desktop runtime reaches the local server and collector
- frontend stable product path works against the stabilized server
- mobile app still works against the existing server bootstrap APIs
- no unrelated formatting churn is included in the merge
- each fixed bug has a short reproduction note in the merge description or branch handoff notes

## Current validation gap in this worktree

- JS dependencies are not installed in `frontend`, `server`, `collector`, or `desktop-tauri`, so `prepare:core`, frontend builds, and full desktop validation are blocked until dependencies are restored.
